## 西雅图这条线到底什么水平

同样是西雅图，标 AS9929 和标 AS4837 的两台机器，国内体验能差出一档。判断一条西雅图线路，先看它写的是哪个线路代号，别看“三网直连”四个字。

四个代号的实际含义：

- **AS4134**：电信 163 骨干，普通国际直连里最稳的一条，美西到国内 145–180ms。
- **AS4837**：联通骨干，广州、上海方向正常，北京方向有可能绕欧洲。
- **AS9929**：联通精品网，比 4837 贵一档，延迟和稳定性都更好。
- **CMIN2**：移动国际精品线，对标电信 CN2 的移动版本。

## 按你的宽带运营商选，别按城市选

下面这组数据来自一份针对 RackNerd 西雅图节点的公开实测，属于同类美西直连机房的普遍表现，不是 JustHost 的实测结果，但运营商之间的差异规律是通用的：

**电信**最省心。回程走 Cogent 到旧金山、圣何塞对接 163 骨干，广州 175–180ms、上海 145–160ms、北京约 165ms，晚高峰丢包也最轻。主力是电信宽带的话，西雅图这个方向基本不会踩坑。

**联通**要分地区看。广州 200–220ms、上海约 170ms 都正常，北京方向因为绕行欧洲，能到 250–360ms。北京联通用户如果对延迟敏感，这一条足够让你换机房。

**移动**延迟数字不算最差，广州 170–230ms、上海约 200ms、北京约 220ms，但晚高峰丢包比电信联通明显。拿移动宽带走关键业务，下单前最好自己 ping 一晚上看丢包曲线。
